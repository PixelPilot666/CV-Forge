【招聘】Agent 开发实习生

岗位职责：
1. 面向开发者构建大模型 Agent 工作流与工具调用能力，持续迭代调试体验；
2. 设计任务编排、状态管理、失败恢复与效果评测机制；
3. 使用 Python 完成服务端原型和工程落地，并与产品、算法团队协作；
4. 在需要外部知识时接入检索增强生成能力。

任职要求：
- 熟练掌握 Python，有 Agent 框架、工具调用或工作流编排实践；
- 能讲清本人负责范围、关键技术取舍和可验证结果；
- 有后端 API、测试评测、可观测或故障处理经验；
- RAG、向量检索、多 Agent 或开源开发者工具经验为加分项。
