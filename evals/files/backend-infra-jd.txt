【招聘】后端 / 基础架构工程师（校招）

岗位职责：
1. 负责高并发后端服务的设计、开发与性能调优，保障系统稳定性；
2. 参与检索/推荐链路的工程化落地，优化查询延迟与吞吐；
3. 设计数据存储与缓存方案，支撑大规模请求；
4. 推动服务的可观测性与工程化评测体系建设。

任职要求：
- 本科及以上，计算机相关专业，应届/在读硕士亦可；
- 熟练掌握 Python，熟悉 FastAPI 等后端框架；
- 熟悉 MySQL / Redis 等数据库与缓存中间件；
- 了解向量检索（FAISS / Milvus）与混合召回者优先；
- 熟悉 Docker、Linux 开发环境；
- 有从 0 到 1 的系统落地经验者优先。

加分项：
- 有高并发、低延迟系统优化经验；
- 有开源项目或顶会论文经验。
